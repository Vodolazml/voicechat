# Private VoiceChat

Приватное desktop-приложение для общения в закрытых пространствах. Цель проекта: сначала собрать понятную программу с пространствами, каналами, подключением к каналам и безопасной основой, затем отдельными этапами добавить настоящий голосовой чат, демонстрацию экрана и текстовый чат.

Весь проект ведем в UTF-8. Интерфейс приложения будет полностью на русском языке.

## Быстрый запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install --no-deps -r requirements-native.txt   # сильный шумодав (RNNoise)

$bytes = New-Object byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
$env:VOICECHAT_SECRET_KEY=[Convert]::ToBase64String($bytes)
$env:VOICECHAT_ENVIRONMENT="development"
python -m uvicorn app.server.main:app --reload --host 127.0.0.1 --port 8765
```

В другом терминале:

```powershell
.\.venv\Scripts\Activate.ps1
python run_client.py
```

Старый интерфейс на виджетах пока доступен как `python run_client.py --classic`.

Первый вход: `admin` и одноразовый пароль, который сервер печатает в консоль при первом запуске. Его сразу нужно сменить.

**Запуск на своём сервере с доменом:** [docs/DEPLOY.md](docs/DEPLOY.md) — одна команда `sudo deploy/install.sh <домен> <email>`.

## Что умеет 0.3.0

- новый интерфейс на QML: пространства, каналы с участниками внутри, сцена звонка с плитками, чат сбоку, настройки во всё окно;
- голос 48 кГц через LiveKit с эхо- и шумоподавлением (стандартное WebRTC или сильное RNNoise), автоусилением и выравниванием громкости друзей, громкость каждого до 300%;
- присутствие в реальном времени: кто зашёл или вышел, все видят сразу; закрытое приложение убирается из канала через вебхук LiveKit;
- демонстрация экрана от 720p30 до 4K30 и 1440p60, просмотр по кнопке «Смотреть», разворот и F11;
- текстовый чат в каждом канале, в том числе внутри голосового: ссылки, @упоминания, непрочитанные, правка и удаление; на сервере сообщения хранятся зашифрованными;
- работа поверх игр: push-to-talk и горячие клавиши без перехвата у игры, трей, никаких всплывающих окон, оверлей «кто говорит»;
- модерация: переместить, заглушить для всех, отключить; лимиты и приватные каналы;
- коды безопасности для сверки E2EE-ключей, список устройств, «Сохранить отчёт» для диагностики.

Подробнее для пользователей: [docs/RELEASE_0.3.0.md](docs/RELEASE_0.3.0.md).

## Безопасность

- только HTTPS/WSS: клиент не подключается к удалённому серверу по `http://`, а к медиасерверу по `ws://`;
- сервер в production не стартует с опубликованными или слабыми секретами, `/docs` выключен;
- короткие access-токены (15 минут) и refresh-токены, которые меняются при каждом обновлении; повтор старого токена завершает все сессии;
- вход по одноразовым приглашениям, список устройств и выход на любом из них;
- голос и демонстрация экрана шифруются на клиентах (E2EE через LiveKit), медиа-ключи раздаются X25519/HKDF/AES-GCM конвертами.

Подробности и схема развёртывания: [docs/DEPLOY.md](docs/DEPLOY.md).

Для раздачи клиента без ручного ввода адреса используйте `client_config.example.json`: скопируйте его в `client_config.json`, впишите `https://chat.<домен>` и оставьте `lock_server_url: true`.

## Порядок разработки

Готово: основа, голос, демонстрация экрана, текстовый чат, установщик и деплой на домен.

Дальше: сквозное шифрование текстового чата, звук из демонстрации экрана (захват звука процесса в Windows), TURN по TLS для очень строгих сетей.
