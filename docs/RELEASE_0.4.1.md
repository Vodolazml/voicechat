# VoiceChat 0.4.1

## Что нового
- **Оверлей:** ползунок «Видимость фона» снова работает (0–100%), по умолчанию фон виден на 50%.
- **Видео на весь экран:** кнопка и F11 / двойной клик открывают только видео на весь монитор; само окно программы
  остаётся как было. Выход: Esc, F11 или кнопка.
- **Своё имя:** Настройки → Аккаунт → «Имя». Новое имя сразу видят все друзья. Логин не меняется.
- **Имя для себя:** правый клик по человеку в канале, на сцене или по имени в чате → «Изменить имя для себя».
  Это имя видите только вы; «Вернуть настоящее» убирает его.
- **Пароль:** цифры и спецсимволы больше не обязательны. Нужно от 8 символов, хотя бы 4 разных, и не из списка
  самых известных паролей. Под полем нового пароля есть шкала надёжности.
- **Регистрация:** поле «Код приглашения» убрано. В пространство можно вступить по коду после входа.

## Исправления
- **Курсор на демонстрации:** показывается ваш настоящий системный курсор (его форма, размер и горячая точка),
  а не нарисованная стрелка.
- **Статус демонстрации:** больше не скачет обратно в «кодер запускается» при коротких паузах в статистике.
  Ответ WebRTC ждём не дольше 3 секунд. Раз в 15 секунд параметры пишутся в журнал.
- **Производительность при 1440p и 4K:** своё превью теперь 10 к/с и шириной не больше 960 пикселей
  (раньше было полноразмерное 20 раз в секунду). Окно программы больше не тормозит, пока идёт показ экрана.

## Сервер
- Новый `PATCH /me` с полем `{display_name}`. Событие `user.renamed` получают все, с кем у вас общее пространство.
- Миграций нет.
