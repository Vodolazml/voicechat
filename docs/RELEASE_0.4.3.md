# VoiceChat 0.4.3

- **Обновление продолжается с места остановки.** Если закрыть программу во время скачивания, при следующем запуске
  загрузка продолжится, а не начнётся заново. Уже скачанный установщик повторно не качается.
- **Окно обновления** показывает проценты и мегабайты («37% · 41 из 110 МБ»).
- **Установщик меньше.** В сборку больше не попадают неиспользуемые части Qt: WebEngine, 3D, PDF, Charts,
  Designer и другие.
- Только клиент, сервер не меняется.
