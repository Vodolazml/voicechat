# VoiceChat 0.4.5

- **Микрофон больше не теряет звук.** Выбранная гарнитура открывалась через старый драйвер DirectSound.
  Он отдаёт звук кусками неровного размера, а программа выбрасывала все неровные куски. У части людей
  терялась примерно треть голоса. Теперь устройства открываются через WASAPI, а звук любого драйвера
  нарезается на ровные куски без потерь. Для динамиков то же самое.
- **Зависший запуск.** Если запущенная копия программы зависла и не отвечает, новый запуск закрывает её и
  стартует сам, а не молча передаёт управление зависшей. Если запуск висит дольше 2,5 минут, в crash.log
  записывается, на чём он застрял.
- **В журнале видно, сколько звука приходит от каждого собеседника** (поле heard: 0 значит, что его не слышно).
- Только клиент, сервер не меняется.
