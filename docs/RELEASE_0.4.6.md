# VoiceChat 0.4.6

- **Выбор микрофона и наушников в настройках срабатывает сразу.** Раньше новое устройство включалось
  только после выхода из голосового канала и повторного входа: программа сравнивала настройки сами с собой
  и не видела, что устройство сменилось.
- **Наушники после отключения и подключения.** Программа следит за устройствами Windows. Если наушники
  выдернули, звук временно идёт через стандартное устройство, а как только их подключили обратно, сам
  возвращается на них. Новое устройство по умолчанию в Windows тоже подхватывается без перезахода.
- Если микрофон молча перестал отдавать звук, программа сама его переоткрывает.
- Если выбранное устройство недоступно, появляется уведомление, а не тихое переключение.
- Только клиент, сервер не меняется.
