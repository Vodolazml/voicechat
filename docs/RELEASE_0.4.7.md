# VoiceChat 0.4.7

- **Звуки играют сами по себе, а не внутри звонка.** Раньше они подмешивались в звук звонка, и каждое
  переоткрытие звука (вход, выход, смена канала, переподключённые наушники) обрывало звук на середине.
  Теперь у звуков свой поток: они не пропадают при подключении и отключении и не портят звук звонка.
- **Новые записанные звуки:** «подключение» и «отключение от голосового канала» вместо пищалок, новые
  «включен» и «выключен» для кнопок микрофона и звука. Тишина в начале записей обрезана, громкость
  выровнена.
- **Свой вход слышно сразу по нажатию**, а не через секунду, когда ответит медиасервер.
- **Если несколько человек зашли или вышли разом**, или кто-то зашёл, пока ещё играет объявление,
  объявление звучит один раз. Вход и выход звучат по очереди, а не друг поверх друга. Новое нажатие на
  микрофон обрывает предыдущую подсказку, а не ждёт её.
- **Оверлей поверх всех окон.** Он больше не прячется, когда сворачиваешь VoiceChat, и раз в секунду
  возвращается наверх, если игра или другой оверлей оказались над ним. Поверх игры в эксклюзивном
  полноэкранном режиме Windows окна не показывает: для оверлея выбирайте в игре «полноэкранный в окне»
  (borderless).
- Эхоподавление теперь знает и про эти звуки: подсказка из колонок не уходит собеседникам через микрофон.
- Только клиент, сервер не меняется.
