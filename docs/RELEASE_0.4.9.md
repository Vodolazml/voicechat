# VoiceChat 0.4.9

- **Обновления качаются в 4 потока.** Одно соединение до сервера упиралось в расстояние (около 1–4 МБ/с),
  четыре параллельных куска заполняют канал: 93 МБ скачались за 9 с вместо 67 с. Если связь оборвалась
  или программу закрыли, каждый кусок докачивается с того места, где остановился. Подпись и SHA-256
  проверяются как раньше. В журнале видно время и скорость загрузки.
- **Меньше поводов для Microsoft Defender:**
  - загрузчик программы собран из исходников, а не взят готовым (готовый загрузчик PyInstaller антивирусы
    часто помечают сам по себе);
  - у программы и установщика заполнены сведения об издателе, версии и авторских правах;
  - клавиатура читается только во время звонка и только для назначенных горячих клавиш.
- **Правовые документы и согласие.** На сервере появились страницы /privacy (политика
  конфиденциальности), /terms (условия использования), /consent (согласие на обработку данных) и /licenses.
  При регистрации нужно поставить галочку согласия; у старых аккаунтов программа один раз попросит
  согласие. В «Настройки → Аккаунт» можно удалить свой аккаунт. Старые данные удаляются по сроку хранения.
- **Лицензии.** Список компонентов с открытым кодом и тексты их лицензий (THIRD_PARTY_NOTICES.md) лежит
  в папке программы и открывается на странице /licenses.
- **Сервер (при выкладке):** установщики отдаёт сам веб-сервер Caddy прямо с диска, а не процесс API.
  Большие загрузки больше не делят один процесс с событиями чата. API пересобирается, база получает
  миграцию 0006 (отметка о согласии).
