# VoiceChat 0.5.3

- **Картинки в чате видны сразу.** Скриншоты и фото показываются прямо в сообщении, скачивать не нужно. Клик открывает картинку в полном размере, кнопка со стрелкой сохраняет её.
- **Файлы сначала прикрепляются, потом отправляются.** Ctrl+V, перетаскивание или «+» кладут файл над полем ввода с предпросмотром; лишний можно убрать крестиком, а отправляется всё по Enter (вместе с текстом). Тот же скриншот дважды не прикрепится.
- **Отправленная картинка появляется в чате сразу** с пометкой «отправляется…», не дожидаясь сервера.
