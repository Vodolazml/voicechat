# VoiceChat 0.5.4

- **Короткий обрыв интернета больше не «выкидывает» из канала.** Раньше после секундного обрыва голос сам переподключался и тебя было слышно, но друзья видели, что ты вышел. Теперь сервер не считает выходом смену подключения, а программа сразу после переподключения подтверждает, что ты в канале.
