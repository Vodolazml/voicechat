# VoiceChat 0.5.6

- **Открытая программа больше не отнимает кадры у игры.** На главном экране логотип бесконечно «дышал», а на экране входа плавал фон. Из-за этого программа перерисовывала окно с частотой монитора, даже когда оно было за игрой: на ноутбуке это стоило до трети FPS. Теперь анимации идут, только пока окно VoiceChat активно. Когда переключаешься в игру, программа ничего не рисует.
- **Чужая демка не грузит процессор, пока её никто не видит.** Пока окно свёрнуто или на весь экран запущена игра, видео собеседников не принимается. Вернулся в программу, и картинка появляется через пару секунд. Звук это не затрагивает.
