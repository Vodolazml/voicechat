# VoiceChat 0.5.7

- **Ещё меньше нагрузки, когда программа в фоне.** Значок загрузки в текстовом канале крутился без остановки, даже когда программа за игрой, и окно перерисовывалось каждый кадр. Теперь он крутится, только пока окно активно, и только когда видно начало переписки. Проверка микрофона в настройках тоже выключается, когда переключаешься в игру.
- В отчёте видно, на каком шаге обработки пропадал звук и вернулся ли он после автоматического восстановления.
